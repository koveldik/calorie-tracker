## 🚀 Быстрый запуск

### 1. Запуск через Docker Compose (рекомендуемый способ)
Убедитесь, что Docker запущен, и выполните в терминале в папке `calorie_tracker`:

```bash
docker-compose up --build -d
```

### 2. Ссылки сервисов:
- **Веб-интерфейс (UI):** [http://localhost:3000](http://localhost:3000)
- **API Swagger / Документация эндпоинтов:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **База данных PostgreSQL:** порт `5432`, БД `calorie_tracker`, пользователь `postgres`, пароль `postgrespassword`.

## 👤 Тестовые учетные записи

При первом запуске база данных автоматически заполняется тестовыми учетными записями и базовым справочником продуктов:

| Роль | Логин | Пароль | Возможности |
|---|---|---|---|
| **Клиент** (`Client`) | `client` | `client123` | Ведение своего дневника питания, расчет БЖУ порций, добавление пользовательских продуктов, установка нормы калорий. |
| **Администратор** (`Admin`) | `admin` | `admin123` | Модерация и верификация любых продуктов в каталоге, удаление продуктов, просмотр истории активности всех пользователей. |
