# CalorieTracker — Информационная система учета питания и трекинга калорий

Модульное веб-приложение для ведения дневника питания, автоматического расчета калорийности и баланса макронутриентов (белки, жиры, углеводы), а также управления каталогом продуктов.

---

## 🛠 Технологический стек

- **Backend:** Python 3.11, FastAPI, SQLAlchemy, Pydantic, JWT (Jose), BCrypt
- **Database:** PostgreSQL 15
- **Frontend:** HTML5, CSS3, JavaScript (SPA), Nginx
- **Инфраструктура:** Docker & Docker Compose

---

## 🚀 Быстрый запуск

### 1. Запуск через Docker Compose
Убедитесь, что Docker Desktop запущен, и выполните в корневой папке проекта:

```bash
docker compose up --build -d
```

### 2. Адреса сервисов:
- **Веб-интерфейс (UI):** [http://localhost:3000](http://localhost:3000)
- **Интерактивная документация API (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)
- **База данных PostgreSQL:** порт `5432`, БД `calorie_tracker`

---

## 👤 Тестовые учетные записи

При первом запуске база данных автоматически заполняется тестовыми аккаунтами и базовым справочником продуктов:

| Роль | Логин | Пароль | Описание |
|---|---|---|---|
| **Клиент** (`Client`) | `client` | `client123` | Ведение дневника питания, расчет БЖУ порций, добавление пользовательских продуктов, установка суточной цели. |
| **Администратор** (`Admin`) | `admin` | `admin123` | Модерация и верификация продуктов в каталоге, удаление любых позиций, просмотр общего журнала активности. |
